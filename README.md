# aiDiary

aiDiary is a lightweight publishing tool that turns AI-assisted thinking into
durable, date-based writing for an existing website.

The project is currently in the design phase. Start with the documentation:

- [Requirements](docs/REQUIREMENTS.md)
- [Design](docs/DESIGN.md)
- [Roadmap](docs/ROADMAP.md)

## ChatGPT Sites experiment

The [ChatGPT Sites publishing PoC proposal](docs/SITES_MVP_PROPOSAL.md) explores conversational draft and publication workflows. It is a proposal, not an approved replacement for the CGI/Markdown design.
